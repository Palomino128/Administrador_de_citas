## 📖 Overview

"Administrador de Citas" is a simple and intuitive web application designed to help users manage their appointments directly in the browser. Built entirely with vanilla HTML, CSS, and JavaScript, this project demonstrates fundamental web development concepts for client-side data management, form handling, and dynamic UI updates without relying on any external frameworks or backend services. It's an excellent resource for learning basic web interactions or for anyone needing a quick, personal appointment tracker.

## ✨ Features

-   **➕ Add New Appointments:** Easily create new appointments with details like patient name, date, time, and symptoms.
-   **📝 View & Edit Appointments:** Display a list of all scheduled appointments and modify their details as needed.
-   **❌ Delete Appointments:** Remove appointments that are no longer required.
-   **💾 Local Storage Persistence:** Appointments are automatically saved in the browser's local storage, ensuring data persists even after closing and reopening the application.
-   **✅ Input Validation:** Basic validation to ensure all required fields are filled before saving an appointment.
-   **📱 Responsive Design:** Adapts to various screen sizes for a seamless experience on both desktop and mobile devices.

## 🚀 Quick Start

This project is a static web application and does not require any build tools or backend services. You can run it directly in your web browser.

### Prerequisites

-   A modern web browser (e.g., Chrome, Firefox, Edge, Safari).

### Installation

1.  **Clone the repository**
    ```bash
    git clone https://github.com/Palomino128/Administrador_de_citas.git
    cd Administrador_de_citas
    ```

2.  **Open in your browser**
    Simply open the `index.html` file located in the root of the cloned directory with your preferred web browser.

    ```bash
    # On most systems, you can just:
    open index.html
    ```
    Alternatively, for a more robust local development experience with a live-reloading server, you can use a simple HTTP server (e.g., Python's http.server or the VS Code Live Server extension).

    Using Python:
    ```bash
    # From the project root directory
    python -m http.server 8000
    ```
    Then open `http://localhost:8000` in your browser.
